CoStudy
Web 体验版

会画图、会跑代码，还记得你卡在哪的伴学 Agent

浏览器里就能试：自定义角色与教法，七阶段教学闭环，答错会判错因并记进错题本。

进入体验版 → 下载桌面版

桌面版才有的能力：跑代码、画函数图与电路、联网检索、本地记忆库。

怎么用

  • 1
    点「进入体验版」，首次会引导你填 API Key
  • 2
    设置 → 模型：填任意 OpenAI 兼容接口的 Key（DeepSeek / 本地 Ollama 都行）
  • 3
    角色工坊 → 选模板 → 开始学习：她会先确认目标、摸你的底，再逐点讲

体验版 与 桌面版
