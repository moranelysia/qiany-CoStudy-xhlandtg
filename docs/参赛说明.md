# 伴学 · 参赛说明

> Cosplay 型全年龄伴学 Agent
> 工程：`C:\costudy`（Electron 45 + electron-vite 6 + Vite 8 + TypeScript 7）

---

## 一句话定位

**先让用户造一个属于自己的伴学角色，再用这个角色陪他学。**

不是「AI 老师」，是「他自己挑的那位陪读」。角色卡完全由用户创建、可由 AI 辅助生成、
可导入社区卡（`chara_card_v2`）；所有教学行为由一层与角色卡**解耦**的学习引擎驱动。

---

## 一、三个可讲的差异化点

### 1. 角色卡是真数据，不是提示词里写死的一句话

- 采用 `chara_card_v2`（SillyTavern 通用规范），**用户可以直接导入社区角色卡**
- 每张卡一个文件，切换只是改一个指针文件（不复制数据，避免两份真相）
- 编辑器按 v2 规范分六组字段：身份 / 人设 / 对话 / 行为 / 学习 / 适龄
- AI 写卡：给 3–5 个关键词 → 生成草稿 → **展示 diff** → 用户确认才写入

> 可演示：新建两张风格截然不同的卡，切换后语气、追问方式、纠错方式都不同。

### 2. 学习是状态机，不是「一句话陪聊」

七个阶段由**程序**持有，模型每轮只拿到「这一步该做什么」：

```
开场 → 目标确认 → 学情探测 → 知识点拆解 → 逐点教学 → 阶段检验 → 收尾
```

为什么不让模型自己记步数：它会漂（聊两句忘了在探测，学生一插话就跳到收尾）。
允许回退（讲完发现没懂 → 回探测），禁止跳步（没确认目标不许开讲），
任何阶段都能收尾（学生说「今天先到这」不能卡着他）。

> 可演示：同一句「这题怎么做」，在不同阶段得到完全不同的回应。

### 3. 记忆不是「全塞进提示词」，是带评分的四因素模型

```
重要性 = 0.3·log10(1+访问次数) + 0.4·e^(-0.0231·天数) + 0.2·情感强度 + 0.1·独特性
```

- **时间衰减**（半衰期 ~30 天）让「三周前的高频记忆」不再永远压着今天的记忆
- 低于 0.35 标为 `compressed`，注入时不再占位置；被再次访问会拉回 `active`
- 第二层压缩：同簇低分记忆合并成摘要（高分条目**不参与归档**，这是自检抓出来的 bug）
- 第三层抽象：从经历里提炼稳定学习习惯

> 可演示：`--memtest` 打印四因素各自的方向性（频率↑分数↑、天数↑分数↓）。

## 二、安全设计（独立于角色卡）

这是参赛材料里最该强调的部分：**安全不能靠「让模型自觉」。**

| 层次 | 做法 |
|---|---|
| **全局等级** | 产品默认 `all-ages`，**卡片只能收紧不能放宽** |
| **提示词层** | 全年龄行为准则追加在系统提示**末尾**（依从度最高），任何角色卡字段覆盖不了 |
| **输出层** | 六类规则扫描，高风险直接拦，命中时平静转回学习（不追问、不说教） |
| **生成层** | AI 写卡出来的卡片强制 `ageRating = all-ages` |

六类规则：性内容 / 自伤 / 依赖诱导 / 索取个人信息 / 心理诊断 / 教伤害。

**诊断类只记录不硬拦** —— 拦死会让正常的情绪倾诉也被挡掉。

### 为什么用规则而不是模型判断

规则可审计、可单测、零延迟、不花钱。模型判断会漂移，一旦被绕过连日志都拿不出来。
「可审计的安全设计」比「我们用模型判断安全」有说服力得多。

### 误伤是被当成功效来测的

`--safetest` 里有一半断言是**必须放行**的学习内容：

```
《哈姆雷特》里讨论自杀的独白            → 放行
二战的暴力历史叙述                      → 放行
安眠药的药物学机制                      → 放行
"这道题难死了"                          → 放行
```

学习产品把课文挡掉，用户会直接关掉这个功能。误伤的代价比漏拦大。

## 三、全年龄向的具体落地

| 冲突 | 原设计 | 现在 |
|---|---|---|
| 学段写死 | 「他是大一学生，学大学课程」 | 六档参数化（小学/初中/高中/大学/成人自学/不限），各自的讲解深度与例子风格不同 |
| 人称写死 | 满篇「他」 | 对学习者用「你」，第三人称用「对方」，不假定性别 |
| 适龄无约束 | 无 | 上述四层安全设计 |
| 依赖风险 | 无 | 行为准则明令禁止「只有我懂你」这类排他表达 |

学段差异不是礼貌差异，是认知负荷差异。小学档要求「一次只讲一个小点、句子要短、
多用生活比方」；成人自学档要求「先给结论与做法，再补原理，不要课堂腔」。

## 四、工程可验证性

**11 个可自动跑的离线自检模式，一条命令全跑完**：

```powershell
pnpm build
.\scripts\check-all.ps1
```

| 模式 | 覆盖 |
|---|---|
| `--selftest` | 角色卡仓库：增删改查 / 导入导出 / 重名 / 指针转移 |
| `--learntest` | 学习会话状态机：合法转移 / 非法跳步 / 回退 / 落盘 |
| `--mistaketest` | 错题本：同毛病合并 / 复发计数 / 只提醒未纠正的 |
| `--pointtest` | 知识点与间隔重复：阶梯 / 掌握度调节 / 过期天数（时间可注入） |
| `--memtest` | 记忆四因素方向 / 旧数据迁移 / 状态压缩 / 画像统计 |
| `--compresstest` | 记忆压缩：只压低分簇 / 兜底不删数据 |
| `--llmtest` | AI 写卡：脏 JSON 抠取 / 重试 / 拒绝无效输出 / 离线桩 |
| `--safetest` | 适龄护栏：六类拦截 + 五条必须放行的学习内容 |
| `--uitest` | 界面接线：真实卡渲染 / 选中同步 / 编辑器保存落盘 |
| `--smoke` | 启动冒烟：窗口标题、IPC、提示词拼装、零旧角色痕迹 |
| `--wintest` | 窗口按钮：最小化 / 小窗化 / **关闭杀进程** |

### 自检抓到的真实 bug（这些是"测出来的"，不是"设计出来的"）

1. 删掉当前角色卡后，**指针不转移** —— 判断「删的是不是当前卡」时文件已删除，永远为假
2. 旧记忆迁移把 `lastAccess` 设成「现在」，导致**时间衰减完全失效**，旧记忆永不压缩
3. 记忆压缩把簇里那条**高分记忆一起归档** —— 只因为它创建得早、排序靠后
4. 编辑器在挂载时捕获 `activeId`，**换卡后保存写进旧卡**（表现为"保存成功但内容没了"）
5. 小窗化被 `minWidth: 900` 夹住，只缩到 904×644 —— 需先放宽最小尺寸、下一 tick 再改尺寸
6. 性内容规则只认「脱…上衣」，漏了「上衣…脱」的语序
7. 教做炸弹被标成 medium 因而放行 —— 教方法必须是 high

## 五、模型接入

**没有 API Key 也能完整运行**：模型层是一个可替换的薄接口，
无 key 时用离线桩，链路（拼提示 → 调用 → 抠 JSON → 校验 → diff）照样跑通并被测试。

```bat
set COSTUDY_LLM_API_KEY=sk-xxx
rem 可选：COSTUDY_LLM_BASE_URL / COSTUDY_LLM_MODEL
```

OpenAI 兼容协议 —— DeepSeek / 通义 / 本地 vLLM 都通用，换服务商只改 baseUrl。
