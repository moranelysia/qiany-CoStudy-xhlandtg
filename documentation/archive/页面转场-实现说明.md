# 页面转场（Apple 风格）· 实现说明

> 2026-11-02。四个页面（首页 / 角色工坊 / 插件 / 伴学）之间加了转场动画。
> 只改实现转场所必需的文件，UI、功能、数据都没动。

---

## 一、先看技术栈（决定了做法）

| 项 | 事实 |
|---|---|
| 框架 | **没有**。渲染端是原生 TS + JS（`app/*.js` 就是返回字符串模板的挂载函数） |
| 路由 | **没有**。`main.ts` 里 `VARIANTS = [mountStudio, mountPlugins, mountCompanion, mountHome]`，`setActive(i)` 直接 `stage.innerHTML=''` 再 `VARIANTS[i](stage)` |
| 动画库 | **没有**。项目里只有 CSS transition/keyframes，没装 motion / framer-motion |
| 固定元素 | 灵动岛 `.proto-picker` 和首页胶囊 `.home-pill` 在 `<body>` 里，不在 `#stage` 内；背景 `body::before` 也是 fixed |

**结论**：不能套 React Router / Motion 那一套。转场只能在"挂载"这一个点上做，
用浏览器自带的 Web Animations API（`element.animate`）——不用引库，也不用改任何页面组件。

---

## 二、做法

### 1. 每个页面套一层 `.page-layer`

`mount()` 不再把页面直接挂到 `#stage`，而是：

```
#stage
  └─ div.page-layer        ← 转场只动这一层
       └─ .app.v-home …    ← 页面原有 DOM，结构没变
```

这一层是新增的普通 div，不影响任何现有选择器（页面仍能 `document.querySelector('.v-comp')`），
尺寸/居中/滚动都不变（`.app` 的 `max-width` + `margin:auto` 在块级父元素里表现一致）。

### 2. 旧页面不销毁，整层挪去"残影层"

切换时：

1. 取出旧的 `.page-layer`（此时先别删，页面内容还在）
2. `#stage` 清空 → 新建 `.page-layer` → 挂新页面
3. 把旧层塞进一个 `position: fixed; inset: 0; pointer-events: none` 的 `.page-ghost`，
   盖在新页面上方（`z-index: 60`，仍低于灵动岛）
4. 旧层淡出 **260ms**，新层淡入 **320ms** —— 两层交叉，中间不会露出白屏
5. 淡出结束后：移除 `.page-ghost`，**同时删掉旧页面注入的 `<style>`**

第 5 步很关键：每个变体 mount 时都会往 `<head>` 注一份自己的样式。
以前是"切屏立刻删"，现在要等 260ms 才能删（否则残影会瞬间变成没有样式的裸 HTML）。
`mount()` 里用 `takeVariantStyles()` 先把样式"摘下来但不删"，转场的 `onExitDone` 再删。

### 3. 动画参数

| | 进入（新页） | 退出（旧页） |
|---|---|---|
| opacity | 0 → 1 | 1 → 0 |
| x | `24px × dir` → 0 | 0 → `-12px × dir` |
| 时长 | 320ms | 260ms |
| 缓动 | `cubic-bezier(0.23,1,0.32,1)`（和 `tokens.css` 的 `--ease-out` 同一条） | 同 |

`dir = 1` 前进（新页从右边来），`dir = -1` 返回（新页从左边来，位移整体取反）。

**关于 `scale 0.985 → 1`（最初需求里有的，后来去掉了）**：
缩放是整体变换 —— 一个 2000px 高的页面，缩放原点在页面 42% 处，
视口顶部离原点很远，1.5% 的缩放会把视口里的内容上下带出十几像素。
用户要求"界面不要上下震荡"，所以 scale 整个去掉，只留**横移 + 淡入淡出**。
要恢复缩放，把 `ENTER_X`/`EXIT_X` 那两个 keyframe 里的 transform 补回 `scale(...)` 即可。

### 4. 方向判定

```
NAV_ORDER = [首页, 角色工坊, 插件, 伴学]   // 用户指定的顺序
dir = rank(新) >= rank(旧) ? 1 : -1
```

注意这不是岛上 tab 的顺序 —— 岛上没有"首页"，它在岛左侧的独立胶囊里，
所以顺序表单独写死一份 `NAV_ORDER`，与 `VARIANTS` 的下标解耦。

### 5. 浏览器前进 / 后退

- 每次 `setActive` 成功后 `history.pushState({ v: i }, '')`
  （**只传 state 不传 URL** —— `file://` 下带 URL 的 pushState 会被安全策略拦）
- 监听 `popstate`：按 `event.state.v` 切回去，方向按 `NAV_ORDER` 自动算 → 所以"返回"从左边进
- 启动时 `replaceState({ v: 当前屏 })`，否则第一次后退会退到空白页

### 6. 固定元素不参与转场

背景（`body::before`）、灵动岛（`.proto-picker`）、首页胶囊（`.home-pill`）都在 `#stage` 之外，
转场只动 `.page-layer`，它们天然不动。视觉上就是"岛和背景稳定，内容页在下面滑进滑出"。

### 7. 性能

- 只动画 `transform` + `opacity`（合成层属性，不触发布局）
- 不动画 `backdrop-filter`。页面里的卡片在"纯白面板"改造后已经没有 backdrop-filter，
  输入框那一层是控件级的小面积，不在动画路径上
- 转场期间才加 `is-moving`（`will-change: transform, opacity`），结束就摘掉，避免常驻图层
- 连续快速切换：新转场开始时 `cancel()` 上一组动画 + 立刻移除上一份残影 + 补跑它没做完的清理

### 8. 无障碍

`prefers-reduced-motion: reduce` 时**完全不播**：不建残影层，直接替换 + 立即清理。

### 9. 不许上下震荡（2026-11-02 追加）

用户反馈"界面不要上下震荡"。查下来是真问题，**不是动画曲线的问题，是滚动位置**：

旧页面滚到 420px 时切屏 —— `#stage` 一清空，文档立刻变矮，浏览器把 `scrollY`
从 420 夹到 246；新页面挂上、文档又变高，它又被改回 270。一次切屏里滚动值变了两回，
画面就是"先往上窜一下、再往下沉一下"，也就是用户说的震荡。

修法两处：

| 改动 | 说明 |
|---|---|
| `mount()` 里先量 `prevScroll` 再清空 | 清空之后文档变矮，那时候读到的滚动值已经是错的 |
| 新页面挂上后 `window.scrollTo(0, 0)` | 新页面一律从顶部出现，不继承上一页的滚动位置 |
| `pageTransition({ fromScroll })` | 残影用它来对齐"用户离开时看到的位置"，所以旧页在淡出过程中纹丝不动 |

另外：进入动画结束后把 WAAPI 动画 `cancel()` 掉（`fill: both` 会让这一层永远挂着
一个 transform，它会变成 fixed 子元素的包含块，滚动和定位可能被悄悄改变）。

自检里加了一条：从滚到 420px 的工坊切到插件，连续采 10 帧 `window.scrollY` 和
`.page-layer` 的 `offsetTop` —— 要求 `scrollY` 立刻归零、`offsetTop` 全程不变（spread = 0）。

## 四、验证

```
dev.cmd typecheck                TC=0
scripts\check-all.cmd            failed 0 / 33，122.7s
run.cmd --transitiontest         PASS（16 项断言）
run.cmd --transitiontest --force-prefers-reduced-motion   PASS（4 项断言）
```

`--transitiontest` 覆盖的四个方向：

| 跳转 | 期望 | 实测 translateX |
|---|---|---|
| 首页 → 角色工坊 | 前进，从右进 | +15.2px（t=90ms） |
| 角色工坊 → 插件 | 前进，从右进 | +6.0px |
| 插件 → 伴学 | 前进，从右进 | +7.2px |
| 伴学 → 插件 | 返回，从左进 | −4.6px |
| 插件 → 角色工坊 | 返回，从左进 | −5.6px |

（位移数值随时间衰减，采样点固定在切换后 90ms，所以每次不完全相同——
这也是"动画确实在跑"的证据。终态一律 `x=0, opacity=1`。）

连点 4 次（首页→工坊→插件→伴学，间隔 60ms）：结束时 `ghost=0, layer=1, opacity=1`。
旧页面注入的样式：只剩当前变体的。

中间帧证据：`工作区\shot\ui-transition-mid.png`（首页淡出、角色工坊从右侧滑入）。
