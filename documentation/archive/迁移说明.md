# 迁移说明（换机器继续干活用）

这个包是 `C:\costudy` 的**完整工作副本**（不含 `node_modules` 和构建产物 `out/`）。

## 一、恢复步骤

1. 装 **Node.js 20 或 22**（官方安装包即可），再装 pnpm：
   ```
   npm i -g pnpm
   ```
2. 解压后进入目录，装依赖（**必须用 pnpm**，仓库里是 `pnpm-lock.yaml`，不要用 npm/yarn）：
   ```
   pnpm install
   ```
3. 构建 + 跑起来：
   ```
   pnpm build
   npx electron .
   ```
   或者开发时热更新：
   ```
   pnpm dev
   ```

## 二、两个 .cmd 脚本需要改

`dev.cmd` 和 `run.cmd` 里写死了**这台机器**的 Node 路径：

```
C:\Users\Lenovo\.dsh\dsh-runtimes\...\node\bin

```
